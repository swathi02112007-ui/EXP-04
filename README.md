# Exp - 4 HOSPITAL MANAGEMENT SYSTEM

# AIM:

To design a Railway Management System using UML diagrams to represent the system's structure, behaviour, and interactions.

# SRS (Procedure):

1. Study the requirements of the Railway Management System.
2. Identify the actors and their roles, such as Passenger, Admin, and Railway Staff.
3. Prepare the Software Requirement Specification (SRS).
4. Identify the functional and non-functional requirements.
5. Design the Use Case Diagram to represent user interactions.
6. Design the Class Diagram to represent classes, attributes, methods, and relationships.
7. Draw the Sequence Diagram to represent the interactions between objects.
8. Draw the Activity Diagram to represent the workflow of railway ticket booking.
9. Draw the State Chart Diagram to represent the different states of a railway ticket.
10. Draw the Component Diagram to represent the components and their dependencies.
11. Verify all six UML diagrams and save them using StarUML.
